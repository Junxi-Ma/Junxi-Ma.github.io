可见光波段地基云量探测物理机理

  • 瑞利散射（Rayleigh Scattering）：大气分子尺度远小于可见光波长（d ≪ λ），散射光强度与波长四次方成反比（I ∝ λ⁻⁴）。短波蓝紫光发生剧烈散射，使晴空呈现清澈天蓝色，在 RGB 通道中呈现 R − B < -25 的显著负色差。
  • 米散射（Mie Scattering）：云滴与水汽颗粒尺度接近或大于光波长（d ≥ λ），各波段散射截面几乎均等（无波长选择性），宏观上呈现各向同性的白光散射，像素色差 R − B ≈ 0 或略大于 0。
  • 自适应色比算法流水线：输入图像 → 圆形天空有效区（ROI）提取 → 逐像素归一化红蓝差 NRBD = (R−B)/(R+B) 直方图统计 → 双峰（且阈值处确有密度谷）时 Otsu 自动求阈 → 单峰时改用物理先验阈值 → 低饱和度补判暗云底/灰云 → 3×3 中值滤波消除椒盐噪点 → 统计云像元占比。
  • 为何用 NRBD 而非原始 R−B：R−B 的绝对值随画面亮度缩放。厚云压暗整幅画面时色差被整体压小、阈值相对偏高，于是大量云漏检，暗云底尤其容易被埋进天空分布里。按亮度归一后，云/天空只由"偏色程度"决定，对曝光不再敏感。在 WSISEG 400 张真值上实测：云量平均误差由 2.83 成降至 0.40 成，云类 IoU 由 0.50 升至 0.82。

轻量端侧 U-Net 卷积神经网络架构

  • 网络结构：采用专为移动端与浏览器边缘侧定制的小型 U-Net（4 层下采样编码器 + 4 层上采样解码器 + 跳跃拼接连接），参数量仅 1.11M，权重体积仅 4.2MB。
  • 三分类输出：输出 3 通道预测 Logits：类别 0 = 天空，类别 1 = 云体，类别 2 = 地物与外缘遮挡物。气象标准云量计算公式严格定义为：云量占比 = N云 / (N云 + N天空)，地物与建筑等遮挡物不进入分母。
  • 数据集与训练：基于 WSISEG 全天空可见光数据集（400 对气象专家真值标注），联合交叉熵与多分类 Dice Loss 优化，并在预处理中引入过曝眩光亮度二分重映射，彻底攻克了传统算法中白云中心过曝亮核被误判为空洞的漏检缺陷。
  • 云边缘后处理（精修）：模型在 256×256 下输出 Logits。旧做法是先在低分辨率取 argmax、再把硬标签最近邻放大，云缘的亚像素判断被整体丢弃、放大后呈块状锯齿。现改为把三通道 Logits 分别双线性放大到显示尺寸后再决策，边缘保持平滑过渡；实测云区边界锯齿像素减少约 12%，云量精度同步提升，且推理仍是单次前向、模型体积不变。
  • 已知弱项（如实说明）：云缘 ±2px 带内召回约 0.48、小于 10px 的碎云召回约 0.68，均低于云体内部（0.99）——边缘与小云是当前模型的短板；对纯白人造色块与实际厚云的判别仍依赖训练域统计。经实测，重训加光度增强、推理前白平衡归一化、翻转 TTA 三种方案均无改善（详见项目 README 的对照表），故未改动模型权重。

纯前端 ONNX Runtime Web 零依赖加载技术

  • 零服务器、零网络上传：双击 cloud_cover.html 本地即可运行，无需云端 GPU 服务器，图片数据 100% 留存用户终端，保护隐私安全。
  • Wasm 虚拟机本地二进制劫持：浏览器在 file:// 协议下运行通常受同源策略（CORS）限制而无法异步 fetch 模型与 wasm 文件。本项目通过在前端劫持全局 window.fetch，将 Base64 编码的 ort.wasm 与 cloud_unet.onnx 作为虚拟二进制流喂入 Wasm 运行时，完美达成双击即开箱可用。

气象观测规范与环境局限性

  • 中国气象局（CMA）云量成数定义：将全天空总面积分为 10 等份，云遮蔽天空的成数（0~10 成）。0~2 成为晴天，3~5 成为少云，6~8 成为多云，9~10 成为阴天。
  • 已知物理局限性：仅适用于白天可见光波段观测；日出日落晚霞时段因全天红光增强可能产生偏差；直视太阳强眩光可能计入云区；浓雾霾天气背景偏白时建议切换为手动阈值微调。
