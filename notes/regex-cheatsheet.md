# 正则表达式速查表

> 这篇笔记故意**没有写 frontmatter**，用来验证回退逻辑：标题取正文第一个 `#` 标题，日期缺失，摘要取首段。

## 常用模式

| 模式 | 含义 |
| --- | --- |
| `^\s+` | 行首空白 |
| `\d{4}-\d{2}-\d{2}` | 日期 `2026-09-25` |
| `(?<=@)\w+` | `@` 后面的单词（后行断言） |
| `(?i)foo` | 忽略大小写匹配 `foo` |

## JavaScript 速记

```javascript
// 全局匹配并收集
const tags = [...'a, b ,c'.matchAll(/[^,\s]+/g)].map((m) => m[0]);

// 校验日期
const isDate = (s) => /^\d{4}-\d{2}-\d{2}$/.test(s);

// 替换所有（字面量用replaceAll更省事）
const slug = title.toLowerCase().replace(/\s+/g, '-');
```

## 注意事项

- 回溯可能导致性能灾难，能用 possessive / 原子组就用（JS 没有，那就拆成两次处理）
- `\b` 词边界在中英混排里行为微妙，中文字符两侧**都算**边界
- 贪婪 vs 懒惰：`.*` 吃到最后一个，`.*?` 吃到第一个匹配就停
