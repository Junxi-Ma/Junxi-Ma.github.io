# 暗色界面的设计 Token 清单

这个网站的所有视觉决策都收敛在一个文件里：`assets/css/tokens.css`。换肤时只改这一个文件，全站跟随。

## 为什么是琥珀金？

试过不少强调色。在近黑（`#0A0A0B`）的底子上：

- **蓝色**太容易联想到默认的「蓝白配色」，正是想避开的
- **紫色**是 Linear 的招牌，好看但撞款
- **琥珀金**有编辑感和奢侈品牌的气质，和黑金组合天然高级，而且和中文黑体不冲突

## 核心配色

```css
:root {
  /* 背景层级 */
  --bg: #0a0a0b;          /* 页面底色 */
  --surface-1: #111214;   /* 卡片表面 */
  --surface-2: #17181b;   /* hover 抬升 */

  /* 发丝线：暗色界面的骨架 */
  --border: rgba(255, 255, 255, 0.08);
  --border-hover: rgba(255, 255, 255, 0.22);

  /* 文本三级层次 */
  --text-1: #f4f4f5;      /* 标题 */
  --text-2: #a1a1aa;      /* 正文 */
  --text-3: #787b84;      /* meta */

  /* 强调色 */
  --accent: #f2a93b;
  --accent-hover: #ffc061;
}
```

## 对比度检查

暗色界面最容易翻车的地方是「灰阶看着舒服，实际不达标」。这几组都过了 WCAG AA：

| 变量 | 色值 | 对比度（相对 #0a0a0b） |
| --- | --- | --- |
| `--text-1` | `#f4f4f5` | ≈ 17:1（AAA） |
| `--text-2` | `#a1a1aa` | ≈ 8.5:1（AAA） |
| `--text-3` | `#787b84` | ≈ 5.2:1（AA，小字也过） |
| `--accent` | `#f2a93b` | ≈ 9.8:1（AAA） |

## 字阶

- 大标题：`clamp(40px, 6vw, 72px)` —— 流式缩放，不用为每个断点写字号
- 笔记正文：`17px / 1.85` —— 中文长文需要比英文更松的行高
- mono 微标签：`12px`，字距 `0.1em`，全大写 —— 制造「仪表盘」式秩序感

## 动效曲线

```css
--ease: cubic-bezier(0.16, 1, 0.3, 1); /* 出弹快、收尾缓，Linear 系动效的秘诀 */
--dur-reveal: 600ms;                    /* 滚动显现 */
--dur-hover: 200ms;                     /* 悬停反馈 */
```

> 一个容易忽略的细节：所有动效都要在 `prefers-reduced-motion: reduce` 下降级，尊重系统设置的用户不该被动画晃到。
