## 三、记忆框架

**1. 族与属的对应靠"字辈"**

- 高云全是"卷"字辈：卷云、卷积云、卷层云（3 属）
- 中云全是"高"字辈：高积云、高层云（2 属）
- 低云五个：雨层云、层积云、层云、积云、积雨云（5 属）

**2. 简写首字母跟着"字辈"走**

- 卷 → C 开头（**C**i、**C**c、**C**s）
- 高 → A 开头（**A**c、**A**s，拉丁 Alto- = 高）
- 低云各自记：N**s**（雨层）、**S**c、**S**t、**C**u、**C**b

**3. 形态口诀（按族背）**

- 高云：**积 · 波 · 层**（Ci 积 → Cc 波 → Cs 层）
- 中云：**波 · 层**（Ac 波 → As 层）
- 低云：**层 波 层 积 积**（Ns 层 → Sc 波 → St 层 → Cu 积 → Cb 积）

**4. 拉丁学名 = 属名前缀 + 类特征后缀**

| 前缀 | 含义 | 后缀 | 含义 |
| --- | --- | --- | --- |
| Cirro- / Cirrus | 卷 | hum | 淡 |
| Alto- | 高（中云） | cong | 浓 |
| Cumulo- / Cumulus | 积 | calv / cap | 秃 / 鬃 |
| Strato- / Stratus | 层 | tra / op | 透光 / 蔽光 |
| Nimbo- | 雨（降水） | cug | 积云性 |
| Fracto- | 碎 | cast / lent / flo | 堡状 / 荚状 / 絮状 |
| | | fil / dens / not / unc / nebu | 毛 / 密 / 伪 / 钩 / 匀 |

所以"透光高积云"= Alto + cumulus + translucidus → Altocumulus translucidus，简写 Ac tra。会拆词根，大部分拉丁学名可以现场拼出来。

## 四、易错点清单

- **雨层云 Ns 是低云**——名字带"层"但属低云；**高层云 As 是中云**——带"高"但不是高云。
- **碎积云的简写是 Fc**，不是"Cu fra"；碎字辈单独记：Fc（碎积云）、Fs（碎层云）、Fn（碎雨云）。
- "积云性"跨两属：积云性**层**积云 Sc cug、积云性**高**积云 Ac cug，只换属前缀。
- 荚状（lent）、堡状（cast）也跨属：Sc lent / Ac lent、Sc cast / Ac cast。
- **伪卷云 Ci not** 来自 nothus（伪），不是 night；**密卷云 Ci dens** 来自 densus。
- 毛卷云 Ci fil 与毛卷层云 Cs fil 同后缀不同属；匀卷层云是 **Cs nebu**（nebulosus）。
- 层云 St、雨层云 Ns、卷积云 Cc 三属"属名 = 云类名"，没有独立云类简写（除自身）。
- 拉丁拼写细节：translucidus（透光）、opacus（蔽光）、lenticularis（荚状）、castellanus（堡状）、capillatus（鬃）、cumulogenitus（积云性）最容易拼错，考前重点过一遍。

## 五、成因与演变：三类云怎么来的

<div class="mk-box mk-box--key">
成云两件套：<b>凝结核或凝华核</b> ＋ <b>水汽达到饱和</b>。气温和水汽含量决定空气能否达到饱和——气温越高、气压越大，空气需要"装下"更多的水汽才能饱和。达到饱和的途径有<b>降温、增湿、降温＋增湿</b>三条，但实际大气中以<b>空气的上升降温</b>为主。
</div>

| 形态 | 成因 | 外貌 | 成员 |
| --- | --- | --- | --- |
| 积状云 | 对流上升 | 底平顶凸、个体分明、垂直发展 | 淡积云 → 浓积云 → 积雨云 |
| 层状云 | 自身冷却；气团沿锋面缓慢抬升 | 均匀幕状、遮天蔽日 | 卷层云、高层云、雨层云、层云 |
| 波状云 | 气流的波动（多在逆温层附近） | 成行成群的云条云块，沿水平方向散布 | 卷积云、高积云、层积云 |

**积状云的发展演变**（对流由弱到强）：

淡积云 Cu hum → 浓积云 Cu cong → 秃积雨云 Cb calv → 鬃积雨云 Cb cap

- 凝结高度<b>低于</b>对流上限才可能有云，两者差值越大云越厚；
- 淡积云对流弱、云体小；浓积云上升气流强盛、垂直猛长；到积雨云阶段顶部被对流上限（稳定层）挡住，转为<b>水平铺展</b>——先秃（花椰菜顶变平圆滑）后鬃（长出纤维状马鬃/铁砧）。

<div class="mk-box mk-box--tip">
课件两道思考题：<br>
① 积云为什么没有融合连成一片？——每朵积云是一个独立发展的对流泡，云块之间是补偿下沉气流，抑制合并，所以个体分明、互不相连。<br>
② 积状云不同阶段垂直气流速度怎么变？——淡积云弱 → 浓积云强盛 → 积雨云内部仍强、顶部受阻转水平铺展成砧。
</div>

层状云是<b>暖湿气团沿干冷气团（锋面）缓慢爬升</b>或自身冷却形成的，抬升平稳 → 云层均匀成幕；波状云则是逆温层附近的波动把湿空气抬过凝结高度，波峰成云、波谷散开。

## 六、波状家族三兄弟：视张角定生死

同为"积"字辈的波状云，靠云块的<b>视张角</b>区分：

| 云属 | 视张角 | 一眼看 |
| --- | --- | --- |
| 卷积云 Cc | 小于 1° | 细小鳞片成行，像水面涟漪 |
| 高积云 Ac | 1°~5° | 成行成群，形似田垄或波浪 |
| 层积云 Sc | 大于 5° | 大块云条云团，缝隙见蓝天 |

<div class="mk-box mk-box--tip">
随堂原题：图中云块视张角在 <b>3° 左右</b> → 高积云（Ac 区间 1°~5°，且成行似田垄）。大于 5° 选层积云，小于 1° 选卷积云。
</div>

高积云比层积云<b>多</b>一类"絮状"（Ac flo）；荚状、堡状、积云性跨 Sc / Ac 两属。

## 七、十属外貌特征速查

| 云属 | 识别要点 |
| --- | --- |
| 卷云 Ci | 丝缕状结构、柔丝般光泽，分离散乱；日出前/日常染黄橙色 |
| 卷积云 Cc | 白色细鳞片成行成群，像微风拂过水面的涟漪；无暗影 |
| 卷层云 Cs | 薄幕状均匀云幕；日月有晕，<b>有晕才能证明它在</b> |
| 高积云 Ac | 块状片状球状，成群成行似田垄/波浪 |
| 高层云 As | 均匀幕状、常有条纹结构；隔云看日月轮廓朦胧可辨 |
| 雨层云 Ns | 厚而暗灰、遮蔽全部天空，看不清日月位置；连续性雨雪 |
| 层积云 Sc | 团状片状条状，大块成行；可降间歇性雨雪 |
| 层云 St | 均匀幕状，云底很低，常笼罩山头或高层建筑 |
| 积云 Cu | 底平顶凸（弧形/花椰菜形），个体明显互不相连；向阳面白亮 |
| 积雨云 Cb | 垂直发展极盛如高山；顶部纤维结构（马鬃/铁砧），云底铅黑，伴雷暴大风 |

## 八、谚语对照（课程清单）

| 谚语 | 对应云 | 记忆点 |
| --- | --- | --- |
| 馒头云，天气晴 | 淡积云 Cu hum | 对流弱、云体小，主晴 |
| 天上铁砧云，很快大雨淋 | 鬃积雨云 Cb cap | 顶部冰晶铺展成砧＝成熟积雨云压境 |
| 天上灰布悬，雨丝定绵绵 | 雨层云 Ns | 暗灰厚幕遮天，连续性降水 |
| 天上鱼鳞斑，明日晒谷不用翻 | 透光高积云 Ac tra | 逆温层下稳定层结，主晴 |
| 炮台云，雨淋淋 | 堡状高积云 Ac cast | 中空不稳定，午后对流爆发 |
| 早晨棉絮云，午后必雨淋 | 絮状高积云 Ac flo | 中空扰动强，易发展成积雨云 |
| 天上扫帚云，三天雨淋淋 | 密卷云 Ci dens | 常是积雨云顶解体残留，锋区将过境 |
| 天上钩钩云，地上雨淋淋 | 钩卷云 Ci unc | 逗号状云丝系统侵入＝锋面前兆 |
| 鱼鳞天，不雨也风颠 | 卷积云 Cc | 细鳞<1°，中高空扰动将转坏 |

<div class="mk-box mk-box--warn">
两个易混对：<b>鱼鳞斑（透光高积云，主晴）≠ 鱼鳞天（卷积云，转坏）</b>——斑大而疏、鳞细而密。<br>
随堂还考过一条：<b>"江猪过河，大雨滂沱"——碎雨云 Fn</b>。"江猪"指雨层云底下移动很快的碎雨云（云属上就归雨层云属），出现它说明上面的雨层云水汽充足。选项同时有"雨层云"和"碎雨云"时选<b>碎雨云</b>；没有碎雨云再选雨层云。
</div>

## 九、课堂随测真题（2026-09-29）

10 题里截到 7 题（第 1、9、10 题没存图），逐题对答案：

**2.（多选）层状云的形成原因有哪些？** A 自身冷却；B 气团沿锋面缓慢抬升；C 气流的波动作用；D 冷暖平流交汇
<span class="mk-green">答案 AB</span> —— 课件原句；波动作用成的是波状云，冷暖平流交汇是干扰项。

**3.（单选·图）图中云块视张角在 3° 左右**（成行似田垄） A 层积云；B 高积云；C 卷积云；D 卷云
<span class="mk-green">答案 B</span> —— 见"视张角"一节：1°~5° 是高积云。

**4.（单选·图）飞机上看到的云顶，花椰菜状轮廓已变平坦圆滑** A Cu hum；B Cu cong；C Cb calv；D Cb cap
<span class="mk-green">答案 C</span> —— 秃积雨云：顶部开始冰晶化变平；长出纤维状马鬃/铁砧才是鬃积雨云。

**5.（单选·图）云布满了小半个天空，白色较厚密** A Fc；B Ci fil；C Ci dens；D Ci unc
<span class="mk-green">答案 C</span> —— 密卷云：成片厚密、占天空较大范围（也常是积雨云顶部解体的残留）。

**6.（多选）下列关于云的说法正确的有** A 云既有宏观特征也有微观特征；B 积雨云和雨层云多由水滴、过冷水滴、冰晶混合组成；C 高积云与层积云相比少了一类絮状；D 雨层云很厚呈暗灰色看不清日月位置
<span class="mk-green">答案 ABD</span> —— C 反了：高积云比层积云<b>多</b>絮状（Ac flo）。

**7.（多选）下列关于云的说法正确的有** A 高积云属于积状云；B 高层云云底呈均匀幕状常有条纹结构；C 卷积云云块视张角小于 1°；D 卷云具有丝缕状结构、柔丝般光泽
<span class="mk-green">答案 BCD</span> —— A 错：高积云是波状云。

**8.（单选）"江猪过河，大雨滂沱"指哪种云** A 积雨云；B 高层云；C 雨层云；D 碎雨云
<span class="mk-green">答案 D 碎雨云</span> —— 见"谚语"一节。
