# Stardy 学习系统重建计划（Anki 式闭环 · v2 · 按你的修正更新）

## Context

旧 `public/tools/stardy/` 是"一套硬编码的大气探测学卡片 + 浏览/背诵/问答"，没有调度、没有导入、没有 AI。本计划结合 Anki 26.11b1 源码（已调研）与两个前身项目（Python 桌面版、安卓 Vue 版）的精华，在站点工具位重建完整闭环学习系统：**上传课件/资料 → AI 提取知识体系（人工审核）→ 卡片/挖空/测验 → FSRS 复习巩固 → 错题回流**。

**已确认决策**：
1. AI 接入：浏览器直连 OpenAI 兼容端点，密钥存本机 localStorage（BYO，零后端）
2. 数据存储：本地 IndexedDB 为主 + 设置页手动云备份（Supabase 单行 upsert，按用户隔离）
3. 解析格式：PDF / PPTX / DOCX / 扫描件 OCR（视觉模型）；**主线是上传课件与整理的资料，不做站内笔记自动导入**（md/txt 作为普通文件上传路径支持）
4. 题型：问答闪卡 + 挖空卡（Anki 式 {{c1::}}，独立调度）+ 选择题 + 简答题 AI 批改，出题带配置面板
5. 知识体系：章→节→知识点→细节树 + 前置/拓展/易混关系标注
6. AI 产出先审后入（审核台）
7. Anki 互操作：按科目为单位导出/导入（自有 JSON 格式先行；apkg 三期评估）
8. 验收资料：《大气探测学笔记.pdf》走完整管线
9. 分三阶段交付，每阶段结束可实际打开使用

- Helper：五档自评交互参考、错题本字段设计

## 技术架构（零构建纯 ES 模块）

```
public/tools/stardy/
├── index.html / meta.json / css/stardy.css
├── js/{app,db,models,scheduler,ai,parse}.js + views/*.js
└── libs/   # vendor: ts-fsrs（阶段一）、fflate + pdf.js（阶段二）
```

- IndexedDB 多 store：subjects / docs / nodes / links / cards / quiz / revlog / sessions / settings（文档全文独立存，不塞科目 blob）
- 云备份：schema.sql 追加幂等第十四节 `stardy_backups`（user_id unique、payload jsonb、RLS 仅本人）
- AI 层：端点/密钥/模型配置、JSON-mode→修复回退、用量统计、mock 模式供无 Key 自测、产出带 sourceRef 溯源
- 复习界面：全屏视图、四键带预览间隔、挖空揭示、KaTeX、S/D/保持率显示

## 分阶段交付

**阶段一（复习内核）**：删旧文件、SPA 壳 + 规范头（theme/hue 键、tool-shell.css、返回胶囊、?v= 约定）；db/models 数据层；手动建卡 + 挖空编辑器；ts-fsrs 调度（步骤/fuzz/埋没/leech）+ 全屏复习 UI；总览统计（热图/预测）；按科目 JSON 导出导入；stardy_backups 表 + 云备份 UI。
✅ 验收：建卡→复习→本地持久→备份上云→恢复。

**阶段二（AI 管线）**：parse.js 四格式提取 + 大纲重建 + 分块；ai.js 完整接入；AI 建知识树（分块增量）；审核台（节点/关系/卡片逐条审、批量通过）；卡片批量生成审核。
✅ 验收：导入 PDF → AI 建树 → 审核入库 → 生成卡片开刷。

**阶段三（测验 + OCR + 收尾）**：出题配置面板 → 生成审核 → 选择/填空/简答 AI 批改 → 错题本 + 回流复习队列；OCR 视觉路径（无文字层页/图片→视觉模型，页数与成本提示）；知识树径向总览图；apkg 单科目导出评估。
✅ 验收：《大气探测学笔记.pdf》完整闭环。
