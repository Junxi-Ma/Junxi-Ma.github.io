AES 加解密

把原文和密钥交给 AES 加出密文，对方用同一把密钥解回原文。加解密全部在你的浏览器里用 Web Crypto 完成 —— 原文、密钥和密文都不会离开这台设备。

怎么用？给对方什么？
  1. 左边填好原文，设一个至少 8 位的密钥，点「加密」。
  2. 把右边的密文复制发给对方（走微信、邮件都行，密文本身就是乱码）。
  3. 密钥另走一条路告诉对方：当面说、打电话、或者用另一个渠道。密文和密钥不要从同一个通道发。
  4. 对方打开这个页面，切到「解密」，粘贴密文、填同一个密钥，点「解密」即可看到原文。

注意：密钥一旦丢失，密文无法找回 —— 这是加密的正常特性，不是 bug。忘了密钥只能重来。

🔒 本页没有任何后端请求：算法由浏览器原生 Web Crypto 提供，密钥只存在于当前页面的内存中，刷新即消失，也不会写进本地存储。
